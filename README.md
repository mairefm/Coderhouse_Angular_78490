# 📘 Curso de Angular — Coderhouse (Turma 78490)

Repositório oficial contendo todas as aulas, práticas e evoluções realizadas durante o curso de **Angular da Coderhouse**, ministrado pelo professor Emiliano Pérez.

O objetivo deste repositório é registrar cada etapa da aprendizagem — desde a introdução ao framework até tópicos avançados como RxJS, Testing (SPECT) e NgRx.

---

## 📂 Estrutura do Repositório

O repositório está organizado por pastas, cada uma representando o conteúdo trabalhado em aula:

### **Clase 1 — Introducción a Angular**
- O que é Angular
- SPA vs MPA
- Instalação de Angular CLI
- Criação do primeiro projeto
- Estrutura inicial (`src/`, `app/`, módulos e componentes)

### **Clase 2 — Fundamentos de Angular**
- Componentes: HTML, CSS e TS
- Data binding
- Interpolação e Property Binding
- Diretivas estruturais

### **Clase 3 — Comunicación entre Componentes**
- `@Input()` e `@Output()`
- EventEmitter
- Componentes pai e filho
- Passagem de dados via hierarquia

### **Clase 4 — Angular Avanzado**
- Services
- Injeção de dependências
- Ciclo de vida de componentes
- Pipes do Angular

### **Clase 5 — Programación Reactiva con RxJS**
- Observables e Subscribers
- Criando streams reativos
- Operadores (`map`, `filter`, `tap`, etc.)
- Introdução a Subjects e BehaviourSubject

### **Clase 6 — Organización y Navegación**
- Rotas no Angular
- `RouterModule` e `AppRoutingModule`
- Navegação com `routerLink`
- Parâmetros de rota (`:id`)
- Rotas filhas e rotas protegidas (overview)

### **Clase 7 — Estrategias Avanzadas**
- Lazy loading
- Divisão de módulos
- Otimização de componentes
- Arquitetura escalável com Angular

### **Clase 8 — Testing y Gestión de Estado**
- Testes Unitários com SPECT
- `HttpClientTestingModule`
- Teste de serviços
- Testes de componente (fixtures)
- Introdução à Store (NgRx) e Redux DevTools

## 🚀 Como Rodar Qualquer Projeto das Aulas

1. Instale as dependências:
```bash
npm install
```

2. Execute o servidor Angular:
```bash
ng serve
```

3. Acesse:
```bash
http://localhost:4200
```

Em pastas com API fake, execute também:
```bash
npm run api
```
